## 왜 LG U+ 만 됐나

APN 이 `config.h` 상수로 박혀 있었습니다. 통신사가 갈리는 지점은 **APN 하나뿐**입니다 —
망 등록(attach)은 유심의 IMSI 가 홈망을 결정하므로 KT 유심을 꽂으면 APN 이 무엇이든
등록은 KT 로 됩니다. **틀린 APN 은 PDP 활성(`gprsConnect`)에서만 떨어집니다.**

그래서 이번 변경은 그 한 값을 정하는 로직이 전부이고, 재등록(최대 90초 폴링)을
되풀이하지 않습니다.

## 어떻게 정하나

| 순위 | 방법 | 비용 |
|---|---|---|
| ① | 콘솔 `apn set` 수동 고정 | 0 |
| ② | NVS 캐시 — **ICCID 가 일치할 때만** | 0 |
| ③ | IMSI 앞 5자리(MCC+MNC) 표 | AT 1왕복 |
| ④ | 표에 없는 MNC → 후보 회전(브링업마다 하나씩) | 0 |
| ⑤ | PDP 실패 → 망이 attach 때 내려준 APN(`AT+CGDCONT?` CID 1) | 시도 1회 |
| ⑥ | 나머지 후보 순회 | 예산 90초 |
| ⑦ | 최후 — 빈 APN(망 기본값) | 시도 1회 |

붙은 APN 은 ICCID 와 함께 NVS(`"apn"` 네임스페이스)에 굳어, 다음 부팅부터 ②로 직행합니다.
**값이 바뀔 때만 씁니다** — 재접속마다 쓰면 플래시가 마모됩니다.

```
[APN] internet.lguplus.co.kr (IMSI 45006 → LG U+)
[LTE] 망 등록됨 (ok-home, rssi=21)
[APN] internet.lguplus.co.kr 저장됨 — 다음 부팅부터 바로 사용
```

### 기존 LG U+ 단말은 동작이 그대로입니다

OTA 로 이 이미지를 받은 단말은 NVS 캐시가 없는 첫 부팅에서 IMSI `45006` → 표 적중 →
지금과 **똑같은 APN 으로 한 번에** 붙습니다. 폴백 경로(⑤~⑦)는 실패했을 때만 열립니다.

### 유심 교체 = 갈아끼우고 재부팅

ICCID 가 달라지면 캐시를 무시하고 다시 판별합니다. 별도 초기화 명령이 필요 없습니다
(어차피 유심 핫스왑은 불가 — 모뎀이 부팅 시 한 번만 읽습니다).

---

## ⚠️ KT/SKT APN 은 실기 검증이 안 됐습니다

해당 유심을 보유하고 있지 않습니다. 표의 값은 **소매 LTE 표준값**입니다.

```c
#define LTE_APN     "internet.lguplus.co.kr"   // 45006 — 실기 검증됨
#define LTE_APN_SKT "lte.sktelecom.com"        // 45005 — 미검증
#define LTE_APN_KT  "lte.ktfwing.com"          // 45008 — 미검증
```

**M2M/IoT 요금제는 사업자가 지정한 별도 APN 인 경우가 흔합니다.** 그래서 ⑤~⑦ 폴백과
콘솔 수동 고정을 함께 넣었습니다 — 표가 틀려도 현장에서 재플래싱 없이 끝납니다.

> 레거시/부가 MNC(45002·45003·45004 등)는 확신이 없어 표에서 **뺐습니다**. 확신 없는 코드를
> 넣으면 "잘못된 확신"으로 폴백을 건너뜁니다. 표에 없으면 순회로 흘러가 어차피 후보를
> 다 시도하므로, 모르는 건 비워두는 쪽이 안전합니다.

---

## 현장 절차 — 대부분 재플래싱이 필요 없습니다

USB-C 또는 보조 UART 로 콘솔에 붙어서:

```
apn                    현재 APN·출처·IMSI·ICCID·망 할당 APN·후보 전부 표시
apn set lte.xxx.com    NVS 영구 고정 (재부팅 후 적용)
apn clear              저장값 삭제 — 재부팅 시 재판별
```

**KT/SKT 단말이 안 붙을 때**
1. USB 연결 → `apn` 으로 IMSI·망 할당 APN 확인
2. 통신사에서 받은 요금제 APN 을 `apn set <값>`
3. 재부팅

부팅 배너와 `status modem` 에도 `apn` 줄이 나오므로 시리얼만 봐도 원인이 잡힙니다.

> ⚠️ **KT/SKT 신규 단말은 OTA 를 받을 수 없습니다** — 붙기 전이니까요. 초기 투입은
> USB 플래싱(`pio run -t upload`)이어야 합니다. 이 `.bin` 은 OTA 용 app 이미지이지
> `0x0` 통합 이미지가 아닙니다.

```

ota-manifest.json                  배포 메타 — url 채워서 사용

```

## 배포 전 체크리스트

- [ ] 업로드한 파일의 MD5 가 위 값과 일치 (`md5 -q <file>`)
- [ ] `ota_start.json` 의 `version` 이 정확히 `0.3.7` — 불일치면 성공해도 ack 가 `failed`
- [ ] `ota_start.json` 직렬화 길이 **< 1,000 bytes**
- [ ] URL 이 `http` 로 시작하고 단말에서 접근 가능
- [ ] 대상 단말이 `cmd` 구독 성공 상태 (`status server` 에서 확인)
- [ ] 단말 전원 안정 — 재부팅 후 10분 안에 MQTT 에 못 붙으면 **자동 롤백**됩니다
- [ ] 1대 선행 배포 후 확대
- [ ] 배포 후 `info` 또는 `status modem` 에서 `apn` 줄이 `(IMSI 판별)` 또는 `(NVS 캐시)` 로
      나오는지 확인 — LG U+ 단말에서 폴백 로그가 보이면 판별이 안 된 것입니다
